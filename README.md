# Nolan

在 Mac mini 终端运行的 GPT 对话与 AI 漫剧制作助手。启动就能自由聊天、讨论创意、写故事和修改方案，不需要先提供小说或创建制作项目。你决定制作时，GPT 再调用 Nolan 的工具规划分集、资产和分镜。**每个视频片段都由你最终审批，GPT 只提供检查报告；整集完成后再由你观看并批准，才开始下一集。**

默认入口采用原生 Codex 对话界面，支持流式回答、多轮上下文和会话恢复，Nolan 制作能力通过专用 MCP 工具提供。本地审片页面用于观看素材和成片、批准版本、提交修改意见。视频生成使用火山引擎官方 Ark API；GPT 可选择 ChatGPT 订阅或 OpenAI API。即梦网页会员、现有即梦 CLI 登录与火山 API 权限互不等同。

本项目已包含真实 API 适配器和本地模拟测试，已在用户授权的项目中运行 GPT、图片和视频生成。独立音乐和转写服务仍需按所选服务验证。演示素材带有 `NOLAN DEMO / SYNTHETIC PLACEHOLDER` 标记，只用于检验流程；模型权限、账户费用和生成质量以实际服务结果为准。

## 安装

需要 macOS、Python 3.11 或更新版本、Git、FFmpeg（包含 ffprobe）。默认 GPT 方式还需要已安装并登录的 Codex CLI。

```bash
git clone https://github.com/jiantianshu2021/Nolan.git
cd Nolan
bash scripts/install.sh
nolan doctor
nolan
```

仓库是私有的，克隆需要具有访问权限的 GitHub 登录。安装脚本将入口放在 `~/.local/bin/nolan`；若终端找不到命令，可先使用该完整路径，或把 `~/.local/bin` 加入 `PATH`。程序需要在运行制作任务时保持启动，关闭终端后可以从项目目录继续。

从 Norlan 升级后，推荐用 `nolan` 启动，旧命令 `norlan` 仍可兼容使用。已有项目、GPT 登录和会话不搬迁：内部 Python 包与 pip 分发名仍为 `norlan` / `norlan-agent`，数据继续保存在 `~/.local/share/norlan`，连接配置继续保存在 `~/.config/norlan`。现有 `NORLAN_*` 环境变量仍有效；安装脚本也接受新的 `NOLAN_INSTALL_DIR`、`NOLAN_BIN_DIR` 和 `NOLAN_PYTHON`。

每次安装都会创建独立的 `~/.local/share/norlan/runtimes/<版本>-<随机标识>/venv`，包括重新安装同一个版本。安装成功并核验两个启动入口的版本后，才切换 `nolan` 和兼容命令；失败时原入口继续可用。旧 `venv` 和历史运行目录保留，正在生成的旧进程仍读取自己的代码。等当前任务结束，再退出原会话并运行 `nolan --resume`，即可加载新版本。

升级本身保留项目的暂停状态，不自动恢复制作或提交新任务。已提交任务的 ID 和历史费用保留；你明确继续后，先查询原任务，不因升级重新生成。重启会话用于加载新规则，不等于批准某个视频版本。

直接输入 `nolan` 打开新的 GPT 对话，不会自动进入旧演示项目。你可以说“先聊聊我的故事，不要开始制作”，也可以贴入故事，或明确提供 TXT/MD 小说路径让它读取。对话可以持续修改创意；决定制作时，直接说“把我们刚才确定的故事创建成漫剧项目”。

```bash
nolan                    # 新的自由对话
nolan --resume           # 恢复最近的 Nolan 对话
nolan chat ./my-drama    # 带着指定制作项目开始对话
nolan setup              # 选择或切换 GPT 连接方式
nolan connection         # 查看当前连接选择
```

原生对话里的 `/new` 是新对话，不是旧控制台的导入小说命令。导入小说直接使用自然语言即可。退出后制作文件与历史仍保留；重新打开可让 Nolan 查看项目并继续。

### 选择 GPT 连接

运行 `nolan setup` 后选择：

- **ChatGPT 订阅**：使用现有 ChatGPT 登录与账户额度，默认保留当前的订阅方式和模型选择。
- **OpenAI API**：填写自己账户可用的模型 ID，在本机终端隐藏输入 API Key；也可从终端的 `OPENAI_API_KEY` 环境变量读取。认证由官方 Codex CLI 保存到 Nolan 的独立 API 登录目录，密钥不会写入项目或仓库。

连接选择会保存，订阅和 API 的登录目录、会话各自独立；切换不会复制两边的登录凭据或静默改用另一个服务。自由对话的 API 费用由 OpenAI 账户单独计费，**不受漫剧项目预算控制**。制作流程内部的 GPT API 调用必须设置项目预算和 `caps.llm`，与媒体调用一起记账。账户级消费限制应在 API 平台设置。

Nolan 的模型只可使用专用制作工具，不能替你批准资产、视频片段或成片、提高预算或直接改写项目状态。需要审批时，它打开本机审片页供你操作。预算配置仍由你在终端执行 `nolan configure`。

Nolan 会比较 `PATH` 中的 Codex 与 ChatGPT/Codex 桌面应用内置 CLI，自动使用其中较新的已安装版本，不替换系统安装，也不自动更换你的模型。需要固定某个 CLI 时，可设置 `NORLAN_CODEX_PATH` 或 `brain.codex_command`。

## 先走一遍无付费演示

```bash
nolan demo ./demo-project
nolan console ./demo-project
```

演示创建两集占位分镜，保留规划、资产和逐集审批。`console` 是显式保留的旧流程控制台，演示时不调用 GPT 或付费媒体服务；`nolan` / `nolan chat` 始终是实际 GPT 对话入口。可在另一个终端打开审片页面：

```bash
nolan studio ./demo-project
```

根据终端显示的项目状态和版本操作。批准并不会跳过其余审批；继续制作会推进到下一个需要你决定的位置。

## 用小说开始制作

```bash
nolan new ./my-drama --novel ./novel.txt --mode live
nolan chat ./my-drama
```

可在创建时加 `--brief "竖屏国风漫画，每集约一分钟"` 表达创作要求；分集方案仍需要你批准。

小说使用 UTF-8 文本。GPT 规划包括分集、生成片段时长、段内镜头时间表、对白、角色和场景资产、声音参考与配乐描述。超出一次输入范围时程序会停止并提示拆分，不会静默截掉小说后半段。

新策划默认以每集约 60 秒安排剧情和分集断点；容纳不下时增加集数，不靠加速对白或删掉情节凑时长。已批准的剧集沿用原定时长，资产增补、返修和升级都不会把当前长集自动改成一分钟；用户明确提出其他时长时按其要求策划。

在 GPT 对话中可以查看当前状态、继续制作、提出返工意见、暂停或恢复。人工审批通过审片页或另一个终端进行，例如批准界面上显示的第 1 版规划：

```bash
nolan approve ./my-drama plan plan --version 1
nolan run ./my-drama
```

首次生成资产前，程序会先打开网页，等你选择“由 GPT 自己决定”或“我来描述”。每项实际新资产都有独立选择；内部画外声源记录不增加选择或审批步骤。第二项允许填写资产描述；人物、场景和道具还可粘贴或上传 PNG、JPEG、WebP 参考图片，每张最多 8 MiB、每项最多 9 张。声音资产使用声线描述和原剧本选句，不把图片当作声音参考。全部实际新资产选择完成后才开始生成，之后仍须逐一审批生成的候选资产。终端执行 `nolan run` 到达此步骤时会保持审片服务运行，按 Ctrl+C 可退出。

审批对象可以是 `plan`、`asset`、`episode` 或视频片段 `shot`。每个片段生成一个新版本后，都会等待你看完画面、听完声音，再决定通过或填写返工意见。GPT 检查报告默认折叠，可按需展开；其中的 `pass`、`fail`、`uncertain` 都只是建议，不会自动通过或重新生成。ID 和版本必须来自当前项目；旧页面上的批准不会覆盖新版本。返工意见应指出片段 ID、时间位置与具体问题，例如“E001-S002 的人物转身后服装变了，请保留其他镜头”。

新策划默认把同场景、连续动作或一轮对话组织成约 **10–15 秒的生成片段，每段通常包含 2–3 个镜头**。复杂动作、关键口型、转场或单独控制的表演可以保留短段或单镜；不机械凑满 15 秒。每段只有一次视频请求，共用真实人物、场景和声音参考。`subshots` 记录段内各镜的 `start`、`end`、`prompt`，时间表须从 0 秒连续覆盖片段时长。时间点是创作目标，实际切镜仍需看片确认。减少请求次数能减少提交和审查轮次，但不等于同比减少视频费用。你选择返工时，实际重新生成整个片段；当前没有只修其中一处画面的局部编辑功能。

**真实片段首次生成与返修都先确认提示词。** Nolan 准备完整的最终提示词、对白/播报和实际参考清单，你点击“确认提示词并生成”后才提交这一版。可以先填写意见修改提示词，重写后仍须确认；继续、恢复和重启均不代替这个决定。视频生成后再由你观看并审批，GPT 报告不会触发自动返工。

返修意见可以要求新增人物、场景、道具或声音。Nolan 提出增量资产方案，确认后先回资产选择与试听；实际新资产全部批准后才准备返修提示词。复用已批准素材无需再次生成，不覆盖原计划或已批准的历史资产。系统女声的画外声源绑定由后台维护，不生成人物图片，也不单独展示或要求审批“播报员角色”；你只需选择、试听并批准真正的声音资产。增补方案仍由你确认，后续系统通知复用同一已批准音色。新声音或图片明确失败后停止，必须由你填写意见并明确重试，继续制作不会自动重复试音。具体操作见[审片室说明](docs/dashboard.md)。

真实项目同场景续段默认使用火山官方尾帧，生成时请求并原样保存尾帧、来源任务和哈希；本地抽帧只用于审片。用户明确指定的返工版本可以参考前段完整原视频，原件须与批准版本哈希一致。官方素材不可用时只补取原任务产物或停止，不降级为截图、不自动重生成。已有视频不会因为尾帧下载失败而消失。参考来源、下载有效期及预算处理见[审片室说明](docs/dashboard.md)。

指定片段返工只重新生成你明确选中的片段，包括在整集返工时填写 `shot_ids` 的情况。同场景后续片段和后续集已有视频会保留，交给你复核与新版的衔接；需要修改时再明确选择。整集返工留空 `shot_ids` 表示本集全部片段返工。更新人物、场景或声音资产仍会使相关片段及后续产物失效。

每集制作时，网页展示动态百分比、已完成片段数、计划镜头总数、当前生成或后期步骤，以及已等待时间。百分比按已人工验收片段的计划时长和后期步骤计算，表示制作流程完成度；视频引擎没有提供内部百分比时，会显示正在等待生成，不编造预计完成时间。成片合成完成显示 100%，仍需你人工审批。每个片段持续保留视频卡片、段内分镜安排、当前版本、生成阶段和任务用时；人工通过后不会消失，返工旧版可展开回看。

**新片段尚未批准时，就能在累计拼接中检查接续。** 当前视频保存并完成媒体检查后，程序先用本机 FFmpeg 更新拼接，再请求 GPT 报告。拼接从本集第一段开始，连续纳入已有当前版本的视频，包括待审批片段和返工后保留的后续片段；遇到尚无可用视频或正在更换版本的位置就停止。返工新版完成后自动更新拼接，旧拼接保留在历史中。包含未批准片段的预览会标为待审，供你观看原始画面与声音；它不会批准片段、推进下一段生成，也不增加视频生成请求。配乐和字幕仍在整集后期统一处理。

**已有项目可直接继续。** 已生成或已提交的任务按原方案恢复，不自动合并。若想调整后续短镜，可在 Nolan 对话中说：“保留已经生成的内容，把剩余合适的短镜调整为 10–15 秒片段，先给我审批方案。” GPT 通过 `propose_segments` 只对完全未开始的连续尾部提出分组，保留原剧情、顺序、对白和总时长；跨场景或参考素材过多时不能合并。网页列出原分镜与新片段对应关系，你选择“批准新分段并继续”或“保留原分段”。批准前不执行新生成；旧人物、场景、声音资产以及所有任务、用量、费用记录不改写。

审片页中的图片可点击放大，支持适应窗口、原始尺寸、缩放和拖动查看，也可在新窗口打开原图。按 Esc 或点击关闭返回资产列表。预览显示资产版本和像素尺寸；页面自动更新时保留当前视图，若资产已换版会提示重新打开查看新版本。

```bash
nolan status ./my-drama
nolan preview ./my-drama episode E001
nolan reject ./my-drama episode E001 --version 1 --shots E001-S002 --feedback "转身后服装变化，请修复"
nolan run ./my-drama
```

## 配置账户与预算

复制 [配置示例](examples/settings.example.json)，填写已开通的图片、视频模型 ID 和你核实的保守调用成本上限。示例中的空模型与零成本刻意使付费任务无法启动。

```bash
cp examples/settings.example.json ./settings.json
# 编辑 settings.json 后，在当前终端配置 ARK_API_KEY。
nolan configure ./my-drama --file ./settings.json --budget 30
```

上面 `30` 只是你自行批准的项目预算示例，默认单位为人民币，**不是平台价格报价**。不要原样接受它；按实际模型、分辨率、时长、参考素材与重试需求填写。

| 配置 | 用途 |
| --- | --- |
| `brain.provider: "codex"` | 跟随 `nolan setup` 选定的订阅/API 登录。订阅记录调用次数；API 还须设置 `caps.llm` 和项目预算。 |
| `brain.provider: "openai"` | 可选的直接 Responses API 适配器；需 `OPENAI_API_KEY` 和明确的 `brain.model`。若当前选择订阅，程序会提示连接冲突并停止，不会静默付费。通常保留 `codex` 并用 `nolan setup` 切换即可。 |
| `ark.image_model` / `ark.video_model` | 填写你在火山 Ark 实际开通的模型或接入点 ID，不由程序猜测。 |
| `caps.image` | 每次图片生成的保守费用上限。 |
| `caps.video_second` | 每秒视频生成的保守费用上限；也用于声音试片。 |
| `caps.llm` | 每次 GPT API 调用的保守费用上限；Codex 订阅方式可设为 0。 |
| `max_attempts` / `max_llm_calls` | `max_attempts` 限制每项资产（含声音试片）的累计生成尝试，以及同一版音轨和转录配置的字幕转录尝试；`max_llm_calls` 限制项目 GPT 调用次数。视频片段由每次明确人工返工授权一次新提交，不以 `max_attempts` 自动重试或阻止再次人工返工。 |
| `creative_brief` | 额外创作要求，用于下一次规划；不会自行改写已批准方案。 |

密钥只通过终端环境变量读取，不要放入小说、提示词、配置文件或 Git 仓库。ChatGPT 订阅不包含 OpenAI API 和火山媒体服务费用；即梦网页登录也不能代替 `ARK_API_KEY`。

图片与视频须分别指定模型：`image_model` 使用已开通的 Seedream，`video_model` 使用已开通的 Seedance 2.x；同一方舟 API Key 可以在获得相应权限后调用两者。Seedream 5.0 flash/pro 的图片请求采用其支持的单图参数。已知的模型类型填反会在本地预检时报告，避免发送无效请求。模型 ID 与参数能力请以[官方图片接口](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)为准。

每次付费提交前，程序先写入预算预留。超时或进程中断导致结果不明时保留额度并停止新提交，不把“没有收到结果”当成“没有扣费”。预算是基于你填写单价的本地控制，不能代替供应商的实时账单和账户消费限额；已经提交的远程任务也不会因本地暂停而自动取消。

## 查看费用与核对账单

审片室、`status` 和 `costs` 共用项目费用记录。网页每3秒刷新；新生成任务自动保存用量，点击“同步用量”可补查已有任务，后台查询期间仍可审看页面。也可在 Nolan 对话中要求“同步并查看本项目费用”，由 `get_costs` 查询。查询不触发新生成；已运行的旧版 Nolan 需重启才能加载新后台。

界面会区分三类金额：

| 显示 | 依据与含义 |
| --- | --- |
| 已核对实际费用 | 你核对供应商逐调用账单后导入的金额。没有账单依据时显示“待对账”，不会显示成零元；明确核实的零元费用可以导入。 |
| 按实际用量计费（未对账） | 接口实际返回的用量乘以请求前锁定的公开单价。未计入折扣、赠额、套餐等账单调整，不等于账户扣款。已导入实际费用的调用不再重复加入此项合计。 |
| 预算占用上限、在途预留、结果待核实 | 本地预算控制。仍保留原保守调用上限；若用量金额或核实账单更高，预算占用会提高，不会因导入较低账单而自动释放原额度。 |

查看逐调用记录，或只查询已有视频、声音试片任务的用量：

```bash
nolan costs ./my-drama
nolan costs ./my-drama --json
nolan costs ./my-drama --sync
```

`--sync` 需要当前终端已有方舟凭据。它只向已有任务发出 GET 查询，不提交生成、不下载素材，也不批准资产或解除结果不明的任务。查不到用量时保留未知，不从视频时长、分辨率或本地文件数量反推“实际用量”。账单查询与任务用量查询是两回事：当前命令不会自动读取账户扣款账单。

新调用会保存用量和价格依据。当前内置价格仅覆盖已核实的精确模型 `doubao-seedream-5-0-flash-260915` 与 `doubao-seedance-2-0-fast-260128` 的受支持规格；接入点别名、其他模型、第三方端点或无法核实的设置不会套用相似模型价格。公开价依据为 [火山方舟模型价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh&redirect=1)，本轮核对日期为 2026-10-20。

历史视频若没有保存请求时的价格与参考视频设置，默认只补录接口用量。**只有你已确认这些历史任务均未输入参考视频时**，才使用以下选项，按当前公开价折算；记录会注明这是历史用量的当前价格计算，不是历史账单：

```bash
nolan costs ./my-drama --sync --confirm-no-video-input
```

历史图片通常没有可供补查的异步任务 ID。如果旧版本没有保存图片响应中的 `usage.generated_images`，升级不会从已保存的图片、生成次数或文件数量补造用量；这部分实际费用需要供应商账单依据。

导入账单前，先从 `nolan costs` 获取调用的 `job_id`，并用任务 ID、请求 ID 等信息核对供应商明细。将已核对的逐调用金额整理为 JSON 列表，例如下面的**虚构格式示例**；请替换 ID、金额和账单依据，不要直接导入示例：

```json
[
  {
    "job_id": "voice-hero-EXAMPLE",
    "amount": 0.0,
    "currency": "CNY",
    "bill_reference": "EXAMPLE-BILL:line-001",
    "scope": "per_call"
  }
]
```

```bash
nolan costs ./my-drama --import-bill ./bill-lines.json
```

金额必须与项目币种一致，每条必须有逐调用账单依据。账户总额、日期汇总或月账单不能自行均摊到某个调用。重复导入相同记录不会重复计费；与已有记录冲突时停止导入，不覆盖旧票据。批次中任一记录不合法时，整批不写入。

## 配乐与字幕

配乐在策划阶段考虑，在整集时间线上统一混音。默认 `music.mode` 为 `none`；设为 `file` 并提供本地 `music.file` 可导入已有配乐。设为 `volc` 可接入火山纯音乐服务，需要单独开通权限、设置 `VOLC_ACCESS_KEY_ID` / `VOLC_SECRET_ACCESS_KEY`，并填写 `music.call_cap`。

火山音乐适配器每次生成 30–120 秒纯音乐。音乐连续播放、淡入淡出，并按原声音量自动压低；不会把短音乐随意循环。台词与 BGM 已经混为一条音轨时，FFmpeg 无法无损分离。详见 [声音与配乐说明](docs/audio.md)。

字幕采用最终音频的真实时间戳，不能把分镜中的计划对白直接当作已核实字幕。默认关闭自动转写；将 `subtitles.mode` 设为 `openai` 并填写 `subtitles.call_cap`，可使用 OpenAI 对实际成片音轨转写。它需要单独的 `OPENAI_API_KEY`，不能使用 ChatGPT 订阅代付；`call_cap` 为每集一次转写的保守费用上限。识别错误仍需在每集人工审片时指出。具体配置与支持范围见 [字幕说明](docs/subtitles.md)。

如果只需改字幕错别字，可在对话中说“将第一集字幕的张三改成张山，只修改字幕”。程序保留原镜头、音轨和字幕时间，只修改文字后重新合成，并要求审批新版本；修改真实对白或镜头后则重新建立字幕时间线。

## 当前检查能做什么

- 已批准的资产文件和声音参考会实际传给视频接口；同场景续镜使用前镜实际片尾附近画面，以及审查记录中的末态。
- 每段生成后检查媒体参数并抽样，交给 GPT 写报告。旧单段取首、中、近尾画面；带 `subshots` 的片段增加计划内镜头与切点附近抽样。累计粗剪也会按配置再次抽样检查。
- GPT 报告区分关键叙事、身份或明显空间问题，可接受细节，以及待核实项，并指出画面证据。任何结论都等待你审批，不触发自动返工；建议使用的后期处理并不代表程序已经具备或执行了该工具。
- 单段或累计粗剪报告调用失败时，保存“报告未完成”的 `uncertain` 记录，保留视频供你审看；继续不会自动重新请求该报告。暂停中断仍保持暂停状态。
- 指定片段返工保留受影响的后续视频，等待人工复核衔接；资产更新则使相关片段及后续产物失效。旧文件与历史记录仍保留。

**抽帧审查不能证明整段动作、口型、音色或配乐衔接已经正确。** 当前 GPT 检查不会声称看完视频或听完音轨；每个片段和最终整集都需要你完整观看、听审并批准。角色与声音参考增加生成条件，无法保证模型完全一致。

| 能力 | 当前验证范围 |
| --- | --- |
| 原生终端 GPT 自由对话、前文记忆、退出恢复及 MCP 工具调用 | 已使用本机 ChatGPT 订阅完成真实多轮测试，成功查询现有项目。 |
| 订阅/API 选择、独立认证目录及计费隔离 | 已通过离线测试与本机配置验证；用户 API Key 尚未配置，API 实际推理调用待验证。 |
| GPT 小说规划与结构化返回 | 已通过本机现有 ChatGPT 登录真实调用验证。 |
| 审批、预算、恢复、字幕缓存与指定片段返工 | 使用离线响应和真实状态转换测试。 |
| 抽帧、拼接、原声保留、字幕和混音 | 使用本机 FFmpeg 与合成素材进行实际测试。 |
| Ark 生成、火山配乐、OpenAI 转写 | 已实现官方接口适配和离线测试；真实账户付费链路待小额验收。 |
| 完整视频动作、音色、口型、音乐和字幕内容验收 | 由你逐段及逐集观看、听审并批准，未实现完全自动替代。 |

项目状态保存在制作目录的 `project.json`。`source/` 保存输入，`plans/` 保存规划，`media/` 保存素材，`evidence/` 保存检查证据，`exports/` 保存粗剪与各版成片。恢复制作时使用同一个目录，不要重新创建来绕过未知账单或审批。

保存规划失败时，Nolan 会向 GPT 返回出错的字段位置与修复建议，供其修改候选草案。声音资产必须绑定角色，引用声音的镜头也须引用对应角色；画外声源应在提示词中明确不出镜。关联校验不能保证生成模型不会画出画外人物，仍需审片确认。修正保存失败的规划不会自动批准或触发付费生成。升级后退出并运行 `nolan --resume`，即可在原会话中加载更新后的工具。

```bash
python3 -m unittest discover -s tests -v
```
