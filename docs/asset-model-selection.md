# 资产生成前确认提示词和模型

每次新建或返修资产，先准备完整提示词、实际参考素材及本次模型选项，等待用户确认，再允许提交一次生成。图片资产选择图片模型，声音试片选择支持原生声音的视频模型。选择只作用于这次资产，不改整个项目的默认模型。

图片列表于 2026-10-20 按火山方舟官方[模型列表](https://docs.volcengine.com/docs/ark/model-list?lang=zh)、[图片 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=en)和 [Seedream 5.0 Pro / Flash 教程](https://docs.volcengine.com/docs/ark/seedream-5-0-pro?lang=zh)核对。包含 Seedream 5.0 Flash、5.0 Pro、5.0 Lite 及其官方别名、4.5、4.0。官方标注即将下线的型号会显示说明；列表不代表账号已开通。原有自定义接入点保留，其他未核实 ID 不接受前端提交。

声音试片复用现有视频模型目录，不扩大目录。选项按照已经准备好的试音时长和实际参考素材检查，必须开启 `generate_audio`。不兼容时明确说明原因，不会悄悄缩短试音、去掉参考图或改用别的模型。

用量计费与核实账单保持区分。按官方[模型价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=en&redirect=1)，Flash 每张输出图 0.12 元，Lite 0.22 元，4.5 为 0.25 元，4.0 为 0.20 元。Pro 单图输出按像素档位计 0.30 或 0.60 元，输入首图免费，第二张起每张 0.02 元。只有供应商返回的实际用量才用于公开价折算，不视为已核对扣款。Pro 实际用量计价还要求供应商返回输入图数量，缺少证据时继续显示待核实。自定义接入点价格未知时保持费用待核实，不套用 Flash 价格，也无需设置费用上限。

以上模型及价格快照只用于本次新提交；既有素材、历史价格快照和在途任务沿用原记录，不因下拉选择发生变化。

0.8.2 起新旧项目均不再设置或确认预算。旧项目的费用与调用记录保留，实际生成仍须本次完整提示词、参考素材与模型的人工确认。网页顶部与终端启动行显示实际运行版本；升级后退出旧会话并重新打开审片室，单独刷新旧服务不会加载新版。

## 卡片内的提示词编辑

0.8.3 起，每项资产只显示一张卡片：在卡片内选择创作方式，随后查看完整提示词、选择模型并确认生成。不会在下方另列一组重复的资产窗口。

已有候选的“修改提示词”直接打开上次实际提交的完整文本和对应模型。可以手动编辑，点击“提交提示词并生成”就授权一个新版本；此路径不调用 GPT 改写或再次弹出提示词确认。旧版没有保存完整请求时，会明确标注由现有记录整理的模板。读取或取消编辑不会改变项目，未提交的草稿会在轮询和提交失败时保留。

生成仍使用绑定的参考图片和试音时长，并检查当前资产版本、原文、参考文件和请求结果。旧页面不能覆盖新版本；结果不明的任务先核实原调用。原素材保留，完成后继续等待人工看图或试听审批。
