# 本地审片室

Nolan 的终端对话负责日常控制；审片室用于集中查看分集策划、资产候选、每个视频片段的 GPT 报告和人工审批，以及每集成片。启动方式以 `nolan studio --help` 为准，默认地址是 `http://127.0.0.1:8765`。

## 审批顺序

1. **分集策划**：核对风格、画幅、各集剧情以及镜头时长。批准后先进入资产创作选择；修改意见会交回策划流程。
2. **资产创作选择**：每项资产首次生成前先选“由 GPT 自己决定”或“我来描述”（可粘贴参考图片）。选择前不提交资产生成。终端对话后台自动弹出本项目审片页，同一规划版本只自动弹出一次；也可主动要求重新打开。
3. **资产**：逐一确认人物、场景、道具和声音候选。每次按钮只批准当前资产，未批准的其他资产继续阻止视频生产。声音候选支持音频或视频试听。
4. **逐段审批**：每个片段生成后都停下，展示当前版本、上一段与累计拼接。GPT 检查报告默认折叠，点击可展开；`pass`、`fail`、`uncertain` 均不代替你的决定。看完接续、听完声音并勾选确认后，可通过该段；也可填写意见返工。一次明确返工只生成一个新版本，随后再次等待审批。
5. **逐集成片**：播放本集，核对画面、对白、字幕与音乐。可填写具体时间点和修改要求，只重新生成明确选中的片段；留空将返工本集全部片段。批准本集后才继续下一集。

每集显示动态进度：已验收镜头按计划时长占 90%，后期依次显示配乐、字幕和合成步骤，成片产出并等待审片时达到 100%。页面同时显示当前镜头、完成镜头数和等待时间。这个百分比表示制作流程完成度，不代表供应商的内部生成进度或剩余时间；返工使有效完成量减少时，百分比会相应回退。

GPT 的报告将问题写为关键问题、可接受细节或待核实项，并注明图片及已知时间点。片段和累计拼接的报告均默认收起，按需展开阅读；审批依据是你实际观看的视频。你可以接受不影响观看的细节，也可以要求修改。报告只根据抽样画面，不代表听过音频或检查过全段动作；纸面文字、鞋色和道具摆位等问题是否值得整段重做，由你决定。当前返工是完整片段的新生成，不是局部编辑。报告里的后期建议也不代表程序已经执行了该操作。

单段或累计粗剪报告调用失败时，页面显示“报告未完成”的 `uncertain` 记录，视频仍可播放，交由你审看；继续不会自动重新请求这份报告。暂停导致的中断仍保留暂停状态。

已人工通过的前段及其明确接受的偏差作为后续连续性基准。下一段应承接其实际位置、朝向和动作状态；旧 GPT 的失败意见不会自行撤销人工通过。

真实制作同场景续段默认使用火山返回的**官方尾帧原件**。每次生成请求都开启 `return_last_frame`，原视频与官方尾帧分别保存文件哈希及来源任务；不会把 FFmpeg 审片截图当作等价的生成参考。网页在片段卡片标明实际采用的衔接来源。仅在用户明确授权的指定返工版本中，才可改用前段未经剪辑、转码的原始视频；会先核对远程原件与人工批准版本的哈希，并把输入视频时长纳入预算占用和相应的用量价格。

供 GPT 观察的本地抽帧与送给视频引擎的素材清单分开；GPT 不会把观察图片的序号写成引擎参考图序号，也不能声称已经观看完整参考视频。新生成的视频即使没有取得官方尾帧，仍可播放和审批，页面会提示尾帧尚未保存。下一段需要该素材时只查询原任务补取；取不到、来源不匹配或超过受信期时明确停止，不自动改用截图或重新生成。

官方规则要求同账号、近 30 天的原始产物；任务记录仅可查询近 7 天，下载链接有效期为 24 小时，再次查询不保证链接续期。因此原件会及时下载保存。已有原片的远程地址过期时，需要另行安排原样转存，不能把重新生成当作地址恢复。[官方素材规则](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh)、[任务查询接口](https://docs.volcengine.com/docs/ark/get-video-generation-task-api?lang=zh)。

返工指定片段后，同场景后续片段及后续集已有视频会保留，并等待你复核与新版的衔接，不连带重新生成；需要重做其他片段时再明确选择。资产更新仍会使使用该资产的片段及相关后续产物失效。

本集已有实际对齐字幕时，使用单独的“修改字幕”按钮更正文字，保留原视频镜头和字幕时间，再重新合成与审片。成片卡片会显示独立配乐、字幕烧录与自动检查的限制，并可下载当前字幕文件。

“确认并继续”“批准策划并继续”和“通过本集并继续下一集”会保存这一次审批，再自动启动制作流程。流程在下一个审批节点、预算限制或错误处停下。每次审批都带具体版本；旧页面不能批准已更新的素材。

模拟项目始终显示黄色 DEMO 说明，其画面、音频与费用都用于验证流程，不作为真实生成结果。预算显示已用、已预留和待核实金额；待核实不视为可用余额。

“暂停新任务”阻止后续提交。已经送到供应商的任务可能继续执行和计费。关闭正在执行任务的审片室也会先设置暂停；应重新启动 Nolan 查询持久化任务状态，不要重复提交未知结果的任务。

升级和重新打开会话保留暂停状态，不自动恢复或生成。你明确继续后，已提交任务按原 ID 恢复；待审视频仍等你决定。人工返工仍受项目预算约束，未知结果须先核实，不能通过重复点击继续来重新提交。

## 本地接口

`norlan.dashboard.serve(project_dir, port=8765, open_browser=True)` 启动服务。测试或嵌入可使用 `make_server(project_dir, port=0)` 创建未启动的服务器。

| 地址 | 用途 |
| --- | --- |
| `GET /` | 内置页面，附带本次服务器会话令牌 |
| `GET /api/state` | 经过字段筛选的项目状态 |
| `GET /media/<relative-path>` | 只读取项目状态中引用的媒体文件，支持视频 Range 与 HEAD |
| `POST /api/action` | `approve`、`reject`、`captions`、`run`、`pause`、`sync_costs`，以及下列资产输入操作 |
| `POST /api/asset-reference` | 上传资产参考图：`id`、`version`、`input_revision`、`data_url` |

POST 使用 `application/json`，携带 `X-Norlan-Token`；审批载荷包含 `kind`（`plan`、`asset`、`shot` 或 `episode`）、`id`、`version`。拒绝另外包含 `feedback`，分集可附 `shot_ids`。这些接口只用于本地审片室，不是对公网提供的服务。

资产输入操作仍由用户在网页完成，不向模型暴露代选工具：`asset_input` 携带 `id`、`version`、`input_revision`、`mode`（`gpt` 或 `custom`）和 `description`；`remove_asset_reference` 携带同样的版本信息及 `reference_id`；`asset_inputs_gpt_remaining` 携带 `plan_version`，只确认尚未选择的资产由 GPT 决定，不覆盖已有输入。参考图上传最多 12 MiB JSON 请求体，解码后每张图片最多 8 MiB、每项资产最多 9 张，支持 PNG、JPEG 和 WebP。声音资产使用文字声线描述，不接受图片作为声音参考。

## 访问边界

服务仅绑定 `127.0.0.1`，校验准确的 Host 与 Origin。每次启动使用随机 CSRF 令牌，所有变更均走 POST；普通操作请求最多 32 KiB，参考图上传单独限制为 12 MiB。页面使用内容安全策略，无外部脚本、字体或跟踪器。

媒体路由只允许当前项目状态明确引用的图片、视频、音频或字幕，拒绝路径穿越、符号链接与任意文件读取；SRT/VTT 仅作为附件下载。配置、小说原文、任务响应和凭据不通过状态接口返回。异常响应不包含原始供应商响应或堆栈；项目的提示性错误会再次隐藏常见凭据格式。

这是本机工具，不应将端口反向代理或转发到公共网络。它没有多用户身份系统，也不替代操作系统的账户隔离。

### 分镜制作与累计拼接

每一集持续保留所有分镜卡片，显示片段编号、当前版本、生成阶段和任务耗时。生成完成与人工通过状态分别显示，等待审批或已人工通过的片段均可播放；返工过程中旧视频列入历史版本，不会误标为正在生成的新版本。

没有取得视频的失败会显示“生成失败，等待处理”，并展示本次任务保存的失败阶段、具体原因、HTTP 状态、供应商错误码及请求 ID。诊断信息先经过脱敏和长度限制；不保存或展示完整响应、密钥、签名地址与素材编码。旧版本未记录的原因明确标为缺失，不根据时长或状态猜测。历史尝试的失败信息保留，新的成功视频不会继续挂着上次错误。

明确失败的任务只能由用户选择“重试一次”；刷新、重启或点击继续不会重新提交。提交结果不明时须先核实，不能直接重试。已取得任务 ID 后的查询或下载失败会保留原任务，恢复时继续查询和下载，不再创建视频任务。成功生成后仍等待人工审批。

从本集已有两个连续可用片段开始，新视频保存并完成媒体检查后，就在本机用 FFmpeg 更新累计拼接，无需先批准该段，也无需等 GPT 报告完成。预览从本集第一段顺序纳入当前可用的视频，包含待审批候选，以及返工时保留、仍待复核的后续片段。遇到没有当前视频或正在更换版本的片段会停止，不跳过缺口，也不拿历史旧版填补。

例如第二段返工后，第一、第三段的视频仍保留：第二段新版完成时，页面自动提供“第一段＋第二段新版＋第三段”的拼接，供你同时检查前后接续。包含尚未人工批准的片段时会标为待审。通过片段仍需单独操作，拼接预览不会改变审批结果或让下一段提前生成。

较早的拼接保留在历史中；不再匹配当前片段版本的拼接明确标为历史。当前最长的连续拼接用于集中审看，单段播放器和历史版本仍可分别查看。拼接只使用本机 FFmpeg，不新增视频生成或 GPT 请求；原有 GPT 检查仍按既定节点运行。配乐和字幕在整集后期统一处理，预览保留片段的原始声音。粗剪报告同样不授权自动返工。

每 3 秒刷新进度与阶段说明；仅时间变化不会重建视频播放器。百分比表示整集制作步骤的完成程度；单个供应商任务未返回真实百分比时，显示阶段与已等待时长。重启后可以继续恢复原任务，不会把保存的“生成中”记录误当成仍有本地制作进程。
